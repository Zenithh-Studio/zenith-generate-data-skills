# Producer / orchestration — generation pass

**Role:** Producer / orchestration. **Upstream:** idea and project constraints. **Downstream:** all seven-tab data.

## Ordered work
1. Parse the idea into subject, audience, stakes, central decision and publishing angle.
2. Prepare an editorial blueprint before writing 12-minute narration.
3. Invoke Research, Script, Storyboard, Visual Bible, Image and Motion stages in dependency order.
4. Run full validator, present editorial uncertainties, export only on success.

## Review checklist
- [ ] seven tab ownership
- [ ] central question and title present
- [ ] global validator passes
- [ ] all unverified research disclosed

## Model output contract
Return only JSON for `overview` matching `references/schema.md` and the repository JSON Schema. If the upstream input is incomplete, mark uncertainties instead of claiming that the final project is ready. The stage's checker is deterministic; editorial quality remains a separate human review.

## Quality bar
hook-title consistency, full stage coverage, zero unresolved structural errors.
