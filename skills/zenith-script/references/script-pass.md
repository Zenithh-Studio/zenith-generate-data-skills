# Narration / hook — generation pass

**Role:** Narration / hook. **Upstream:** verified research ledger and positioning. **Downstream:** immutable narration to Shot Master.

## Ordered work
1. Define audience promise and one central historical question.
2. Draft the first 30 seconds: named subject, sharp contrast, causally grounded surprise, open question.
3. Draft full narratable scenes with transitions and evidence-backed consequences.
4. Estimate spoken word budget and lock narration before shot partitioning.

## Review checklist
- [ ] every scene has full narration
- [ ] research IDs resolve
- [ ] no 30-second overstuffing
- [ ] shot anchors reconstruct script verbatim

## Model output contract
Return only JSON for `script` matching `references/schema.md` and the repository JSON Schema. If the upstream input is incomplete, mark uncertainties instead of claiming that the final project is ready. The stage's checker is deterministic; editorial quality remains a separate human review.

## Quality bar
first 30 seconds, accurate causal narrative, exact VO wording.
