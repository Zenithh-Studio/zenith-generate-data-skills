# Shot Master / timecoded cuts (English guide)

Install this folder in your agent skills directory. Read [SKILL.md](SKILL.md), [schema](references/schema.md), and [generation pass](references/storyboard-pass.md).

Check example: `node scripts/zenith-storyboard.mjs check examples/sample.json`.
Run tests: `node scripts/selftest.mjs`.
The sample is a 20-second technical fixture, not a complete documentary.
