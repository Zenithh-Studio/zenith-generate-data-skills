# zenith-storyboard: authoring and model instructions

## Stage-specific technique

Write the first 30-second shot plan before expanding the rest; contrast strategic confidence and material collapse.

## Output discipline

- Use exact field `shots` and stable IDs from the upstream project.
- Write concrete, actionable text. Avoid filler and repeated generic phrases.
- Preserve verified claims and explicit uncertainty.
- Do not claim images, videos or VO have been generated by writing prompts.
- On change, run `node scripts/zenith-storyboard.mjs check <project.json>` and the root validator.

## Input provenance

Keep a source link or upstream record ID for every factual or visual constraint where relevant. Unavailable source verification remains unresolved rather than silently approved.
